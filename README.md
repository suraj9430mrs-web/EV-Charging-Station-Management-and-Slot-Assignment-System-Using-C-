# EV Charging Station Management and Slot Assignment System Using C++

## Project Overview
The EV Charging Station Management and Slot Assignment System is a C++ based project designed to manage electric vehicle charging operations efficiently.

It helps manage vehicle information, monitor charging slot availability, check connector compatibility, and assign suitable charging slots.

## Key Features
- Vehicle information management
- Multiple charging slot management
- Automatic slot assignment
- Connector compatibility checking
- Charging requirements management
- Slot availability tracking

## Technologies Used
- Programming Language: C++
- Concepts: Structures, Functions, Arrays and Data Structures

## How to Run

1. Clone this repository.
2. Open the project in a C++ compiler or IDE.
3. Compile the source code.
4. Run the executable.

```bash
g++ EV_Charging_Multiple_Slots.cpp -o ev_charging
./ev_charging
```
